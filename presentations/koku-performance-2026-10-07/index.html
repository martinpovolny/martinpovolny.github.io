BEYOND THE API

Workers, indexes, partitions and queues

Worker kills · #6325 · live

Error reporting rendered a dataclass that held a QuerySet, re-running the slow capacity query inside the error handler.

Partitions · #6324 · flag off

Next month's table partitions created ahead of time, every 8 hours, create-only.

Manifest index · #6329 · live

Index on manifests by source and creation time for the /sources/ list. Built in prod on 6 Oct: 64 MB, valid.

Rate-limit locks · found today

Expired worker-cache locks still counted as running: one tenant re-queued over 10,000 times on 6 Oct.

HOW WE WORKED

An agent with read-only access, and a written trail

Investigate

An agent queries oc, Gabi, Kibana and CloudWatch directly.

Repeat

Skills and scripts: 3scale extract per org, Gabi replica wrapper, Unleash helper.

Write down

Wiki tracker of every fix, flag and deployment; customer lookup. Each investigation documented. JIRA ticket created.

The human decides what to ship and when; the agent does the counting and keeps the receipts.
