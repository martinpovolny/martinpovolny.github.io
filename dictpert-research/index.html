🆕 Latest: Answer-Construction Modes + Cheap Model Search (September 2026)

🧭 Plan Mode & Rethink Mode

Design + implementation + eval · September 2026

Two new sidebar-selectable dict-mode variants targeting a strategy/coverage failure mode found in eval: the model sometimes narrows its search too early or gives up before covering all relevant dictionaries. Plan mode forces an explicit upfront search strategy (a structured plan tool call) before any lookups, with code-level tracking that nudges the model if it skips a dictionary it planned to check. Rethink mode lets the model self-assess a draft answer as incomplete and request additional search rounds (bounded, so it can't loop forever) instead of settling for a thin answer.

Result: validated on a 33-run batch (11 queries × baseline/plan/rethink) — zero-result rate improved 8% → 3% (plan) → 1% (rethink), generalizing across the whole query set rather than one favorable case. On the germanism-search query specifically, rethink mode nearly tripled the number of confirmed answers found (14 vs. 5 baseline) by twice recognizing its own answer was thin and asking to continue.

💸 Finding a cheap/free model for evals

Provider survey · September 2026

Every prior eval ran on Anthropic's claude-haiku-4-5, which is reliable but not free. Surveyed OpenCode.ai, Hetzner, and OpenRouter for a model cheap enough to run much larger eval batches — the constraint being that dictpert's tool-calling loop needs full tool_choice support (required/none/auto), which rules out several otherwise-promising free models that only support "auto".

Result: google/gemma-4-31b-it via OpenRouter (the paid, non-free tier — the free tier is rate-limited far below dictpert's per-query token usage) turned out to be the cheapest fully-compatible option at $0.09/$0.34 per 1M tokens — a full 33-run eval batch cost $0.27 total, roughly 15-20× cheaper than the same batch would cost on Anthropic, with zero errors and zero leakage. Also found and fixed a compatibility bug affecting Qwen's newer model generation (3.7+): they default to a "thinking mode" that rejects forced tool-calling — fixable with a documented API parameter once traced to the model's own documentation.
